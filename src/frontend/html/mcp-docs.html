HOJ 题库 MCP 服务

通过 MCP 接口，让 AI 助手 / 编程工具直接查询题库、题目详情、排行榜与每日一题。

服务地址
https://xdzn.asia/sse
鉴权方式
请求头 Authorization: Bearer <你的KEY>
返回格式
JSON（MCP 标准响应）
能力
题库 / 题目详情 / 排行 / 每日一题（只读）
需要 API Key 才能访问。Key 由服务提供方发放，请妥善保管。

快速开始

两分钟接入：先列工具，再调用工具。

1. 查看可用工具

curl -X POST 'https://xdzn.asia/sse'   -H 'Authorization: Bearer <你的KEY>'   -H 'Content-Type: application/json'   -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

2. 调用某个工具

curl -X POST 'https://xdzn.asia/sse'   -H 'Authorization: Bearer <你的KEY>'   -H 'Content-Type: application/json'   -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"getRanking","arguments":{"type":"user","page":1,"limit":20}}}'
如果客户端要求 SSE 类型，把地址换成 https://xdzn.asia/sse。

工具列表

以下工具均为只读，调用不会修改任何数据。

listProblems 题库
分页查询公开题库，支持关键词、难度筛选。
  • keyword（可选）
  • difficulty（可选，1-5）
  • page（默认 1）
  • limit（默认 20）
getProblem 题目
获取单题详情：题面、输入输出、样例、标签等。
  • problemId（题号，如 1001）
getRanking 排行
查询用户排行榜，支持全局与近 7 天。
  • type（user / recent7）
  • searchUser（可选）
  • page（默认 1）
  • limit（默认 20）
getDailyProblem 每日一题
获取每日一题（一类训练）的最新媒体。
  • trainKeyword（可选，默认“每日一题”）

客户端接入

把 MCP Server 地址 + API Key 填进客户端即可。

Claude Code（命令行）

claude mcp add hoj --transport sse --url https://xdzn.asia/sse --header "Authorization: Bearer <KEY>"

Claude Desktop / 配置文件

{
  "mcpServers": {
    "hoj": {
      "type": "sse",
      "url": "https://xdzn.asia/sse",
      "headers": { "Authorization": "Bearer <KEY>" }
    }
  }
}

Cursor

Settings → MCP → Add MCP Server,填入：

{
  "type": "sse",
  "url": "https://xdzn.asia/sse",
  "headers": { "Authorization": "Bearer <KEY>" }
}

Cherry Studio

  • 新建 MCP 服务器，类型选 SSE；
  • 地址：https://xdzn.asia/sse；
  • 请求头：Authorization: Bearer <KEY>；
  • 启用后即可在对话中使用该服务工具。

其它 MCP 客户端

所有 MCP 客户端都是配置“MCP Server 条目 + Bearer”，填入：

字段值
类型http（多数客户端）；若客户端只支持 SSE 则选 sse
网址https://xdzn.asia/sse
请求头Authorization: Bearer <KEY>

常见问题

没有 API Key 能用吗？
不能。需要向服务提供方申请 Key，并在请求头 Authorization: Bearer 中携带。
返回 401 怎么办？
Key 缺失或错误。检查请求头里 Bearer 与 Key 是否准确，或联系提供方确认 Key 是否有效。
应该用 http 还是 sse？
优先 http，地址 https://xdzn.asia/sse；若客户端只支持 SSE，用 https://xdzn.asia/sse 并把类型设为 sse。
工具返回的数据范围？
仅公开数据（公开题库、排行榜、每日一题训练），均为只读，不涉及提交/修改。
