其它 Agent 如何接入

本质上任何 MCP 客户端都是“一个 HTTP MCP Server 条目 + Bearer”。

Claude Code

claude mcp add hoj --transport http --url https://xdzn.asia/mcp --header "Authorization: Bearer <KEY>"

Claude Desktop / Cursor（mcpServers 条目）

{"mcpServers":{"hoj":{"type":"http","url":"https://xdzn.asia/mcp","headers":{"Authorization":"Bearer <KEY>"}}}}

Cherry Studio 等：新建 MCP → 类型 HTTP/SSE → 地址 https://xdzn.asia/mcp → 请求头 Authorization: Bearer <KEY>
